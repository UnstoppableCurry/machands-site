给你的云端 AI 代理
一双 Mac 上的手

Give a cloud AI agent hands on your own Mac.

Claude Code、Codex、Cursor 跑在云端时碰不到 Xcode、模拟器、Safari、公证。MacHands 让它们用你自己的 Mac 干活——不用租机器，不用开远程登录，不用懂 SSH。每一手都经你同意。

A free, MIT-licensed agent bridge: menu-bar app on your Mac, CLI and MCP on the agent side.

三步开始

用户只做三步。配对之后选一次授权范围，之后不再打扰。

Three steps. You stay in control of every action.

1

打开 MacHands.app

菜单栏出现一只手。从源码构建，或在仓库的 GitHub Releases 取已发布的应用构建。Open the menu-bar app. A hand icon appears.

2

点「复制给 agent」

得到一段配对文字。配对码 10 分钟有效，只能用一次。Copy the pairing block for your cloud agent.

3

贴给你的云端代理

它会自己执行里面那一行。几秒后菜单栏显示「已连接」。然后选一次范围：开发者、只读、或逐条审批。Paste it into Claude Code, Codex, Cursor, or any agent that can run a command.

常见问题

Short answers. 中文为主，英文对照。

这是外盘搬家 / 磁盘清理工具吗？

不是。MacHands 是给云端 AI 代理用的 Mac 桥：菜单栏 App + CLI/MCP。路径保留的外置磁盘迁移是另一款产品 DataDance，和本站无关。

收费吗？要不要付钱？

不收费。源码以 MIT 开源，没有标价、没有结账、没有 App Store 内购。你可以直接在 GitHub 使用和修改。

How do I get MacHands?

Open the source on GitHub. App builds are published on that repo’s GitHub Releases. This site does not host a separate installer.

需要打开「远程登录」或会 SSH 吗？

不需要。App 自己执行命令，自己就是隧道端。没有 sshd 暴露。

会不会在 Mac App Store 上架？

不会作为商店付费应用来卖。沙盒也拦不住 MacHands 需要的能力（执行命令、键鼠、截别的 App 的屏）。请用 GitHub 上的源码与 Releases。
