Privacy Policy · Last updated: 2026-09-30. MacHands is a free, MIT-licensed menu-bar app + CLI/MCP. It is not a paid disk utility.

1. 范围 / Scope

本政策说明你安装、使用 MacHands（给云端 AI 代理一双 Mac 上的手）时，软件与维护者如何处理信息。软件不收费，没有结账，因此我们不会为付款而收集支付信息。

This policy covers the macOS menu-bar app, the machands CLI/MCP, and optional self-hosted or default relay traffic. There is no store, in-app purchase, or paid license.

2. 在你 Mac 上本地处理的数据

大部分处理发生在本机：

  • 本机身份密钥与配对状态 — 存在 Keychain / 本地应用支持目录，用于和已授权的 agent 通信。
  • 审批范围、黑名单、暂停状态 — 本地设置。
  • 审计日志 — ~/Library/Logs/MacHands/audit.log，记录命令摘要与你的决定。
  • 作业输出等运行时文件 — 在本机应用支持目录，由你删除应用或清空文件时消失。

通知、屏幕录制、辅助功能只在你授权后，用于对应能力（提醒、截屏/录屏、键鼠）。不授权也能用其余功能。软件不会去读 Mail 或 Messages 的内容。

3. 网络

  • 配对与中继：agent 与 Mac 之间的内容用端到端加密（X25519 + ChaCha20-Poly1305）传输。中继只转发密文，看不见命令正文。
  • 配对码：短时、一次性。过期或用过后失效。
  • CLI / MCP：跑在 agent 所在机器上（例如你的云端环境）。它保存的身份文件在那台机器的用户目录里，不经过本站。
  • 没有付款通道：没有支付服务商、没有订单邮箱、没有许可证服务器要你的卡号。

4. 维护者可能收到什么

如果你发邮件到支持地址，我们会收到你写下的邮箱和正文，用来回复问题。我们不出售个人数据。源码与 issue 在 GitHub 上按 GitHub 的条款处理。

5. 保留

本机数据留在你的设备上，直到你删除应用或清掉其支持文件 / Keychain 条目。支持邮件只为处理你的请求而保留。

6. 你的选择

  • 可以不授予通知、屏幕录制或辅助功能；对应能力不可用，其余仍可用。
  • 可随时暂停、撤销某个 agent 的配对，或关掉软件。
  • 可以自建中继，不使用默认中继。

7. 儿童

本软件不面向 13 岁以下（或你所在地最低年龄）的儿童。
