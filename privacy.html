最近更新：2026-09-30 · 维护者：Tianxin Wang · MacHands 是免费的 MIT 开源代理桥（菜单栏 App + CLI/MCP），不是磁盘工具。

1. 范围

本政策说明你使用 MacHands 时，软件与维护者如何处理信息。没有付费服务，因此不会为付款收集信息。

2. 本机数据

大部分处理发生在你的 Mac 上：

  • 身份密钥与配对状态 — Keychain / 本地应用支持目录
  • 审批范围、黑名单、暂停状态 — 本地设置
  • 审计日志 — ~/Library/Logs/MacHands/audit.log
  • 作业输出 — 本地应用支持目录

通知、屏幕录制、辅助功能只在你授权后用于对应能力。软件不读取 Mail 或 Messages 的内容。

3. 网络

  • agent 与 Mac 之间端到端加密（X25519 + ChaCha20-Poly1305）。中继只转发密文。
  • 配对码短时、一次性。
  • CLI / MCP 跑在 agent 那台机器上，身份文件留在那里。
  • 中继只自建，见 relay/README.md。

4. 维护者可能收到什么

你发到支持邮箱的正文与地址，用来回复问题。我们不出售个人数据。GitHub 上的 issue 按 GitHub 条款处理。

5. 保留与选择

本机数据留到你删除应用或清掉其文件。你可以不授予系统权限、暂停、撤销配对，或自建中继。

6. 儿童与联系

本软件不面向 13 岁以下（或当地最低年龄）的儿童。联系：wangtianxin666@icloud.com · 源码：GitHub

Privacy

Last updated: 2026-09-30 · Maintainer: Tianxin Wang · MacHands is a free MIT agent bridge (menu-bar app + CLI/MCP), not a disk tool.

1. Scope

This policy covers how MacHands and the maintainer handle information. There is no paid service, so nothing is collected for payment.

2. Data on your Mac

Most processing stays on your Mac:

  • Identity keys and pairing state — Keychain / local app support
  • Scope, denylist, and pause state — local settings
  • Audit log — ~/Library/Logs/MacHands/audit.log
  • Job output — local app support

Notifications, Screen Recording, and Accessibility are used only after you grant them. The software does not read Mail or Messages.

3. Network

  • Traffic between the agent and the Mac is end-to-end encrypted (X25519 + ChaCha20-Poly1305). A relay forwards ciphertext only.
  • Pairing codes are short-lived and single-use.
  • The CLI / MCP keeps its identity file on the agent machine.
  • Self-host the relay. See relay/README.md.

4. What the maintainer may receive

If you email support, we receive the address and message you send. We do not sell personal data. GitHub issues follow GitHub’s terms.

5. Retention and choices

Local data stays until you delete the app or its files. You can withhold system permissions, pause, revoke pairing, or self-host the relay.

6. Children and contact

The software is not directed at children under 13 (or the local minimum age). Contact: wangtianxin666@icloud.com · Source: GitHub
