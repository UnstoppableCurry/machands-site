Nothing to buy

Last updated: 2026-09-30 · Maintainer: Tianxin Wang

1. There is nothing to buy

MacHands is a free MIT open-source agent bridge: menu-bar app + CLI/MCP. The source is on GitHub. There is no paid service.

This URL is kept so old bookmarks still work. It only says: this is an open-source project, and there is nothing to buy.

2. This is not a disk tool

MacHands is not DataDance and not MacDisk. It does not relocate external disks.

3. How to get it

v0.3.1 is a source release with no signed app attached. Build it on a Mac from the repo README. Self-host the relay; see relay/README.md.
