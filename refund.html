This page used to describe paid licenses. MacHands is now fully open source and not charged. There is no price and no refund window, because nothing is sold.

1. 不收费 / Not charged

MacHands 是免费的 MIT 开源项目：菜单栏 App + CLI/MCP，源码在 GitHub。没有标价、没有结账、没有 App Store 内购、没有付费许可证。

本页保留旧地址，以免书签失效。它不再出售任何磁盘工具，也不再描述任何付费路径。

2. 为什么没有退款政策

没有收款，就没有可退的订单。如果你在别处看到 MacHands 的标价或「内购」，那不是本项目当前的分发方式。

There is no money-back window and no payment processor, because the software is not sold.

3. 这不是 DataDance

路径保留的外置磁盘迁移是另一款产品。本站只描述 MacHands 代理桥。
